Sobel & Canny

An edge is where image intensity changes sharply. Sobel measures that change directly with a pair of small filters; Canny wraps Sobel in a five-stage pipeline to return clean, single-pixel-wide contours. Everything below runs live in your browser — drag the sliders.

01Sobel — the gradient operator

The image gradient ∇I = (Gx, Gy) points in the direction of steepest intensity increase. Sobel approximates each component by convolving the image with a 3×3 kernel that combines differencing (find the change) with light smoothing (resist noise). Blue = negative weight, orange = positive.

Gx  horizontal change
Gy  vertical change
magnitude = √(Gx² + Gy²)
— how strong the edge is

direction = atan2(Gy, Gx)
— gradient points across the edge

Worked by hand — a vertical edge

Take a 3×3 patch straddling a dark-to-bright vertical edge (left column 10, right column 80). Multiply each kernel against the patch and sum.

image patch
Gx = (−1·10 +1·80) + (−2·10 +2·80) + (−1·10 +1·80)
   = 70 + 140 + 70 = 280
Gy = −(10+20+80) + (10+20+80) = 0
magnitude = √(280² + 0²) = 280 (strong)
direction = atan2(0, 280) = 0°
Gradient points horizontally → the edge itself is vertical. A horizontal edge would flip the result: Gx=0, Gy large.

02Canny — the five-stage pipeline

John Canny's 1986 detector is still the default. It turns Sobel's thick, noisy response into thin, connected, well-localised edges through five steps, each fixing a flaw of the one before.

StageDoesFixes
1 · Gaussian blurSmooths the image (σ controls how much)Noise that would trigger false edges
2 · Sobel gradientMagnitude + direction at every pixel— (this is the raw edge signal)
3 · Non-max suppressionKeeps a pixel only if it's the local peak across the edgeThick, fuzzy edges → 1px wide
4 · Double thresholdClassifies pixels strong / weak / discardPicking one threshold is too brittle
5 · HysteresisKeeps weak pixels only if connected to a strong oneBroken edges & isolated specks

Try it: push σ up and watch fine texture vanish but corners round off. Raise the high threshold to keep only the boldest edges; raise low and weak edges stop linking up, so contours fracture. Crank noise with σ=0 to see why smoothing comes first.

The one-line summary

Sobel answers "how fast is intensity changing here, and in which direction?" — a raw, thick, noise-prone gradient. Canny takes that gradient and disciplines it: blur to suppress noise, thin to one pixel, then threshold with hysteresis so only confident, connected contours survive.
